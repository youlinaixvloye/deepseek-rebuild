# 工具及反编译来源

- 原应用：用户提供的 DeepSeek 2.7.1(287) APK，SHA-256 为 `86e77d419fed957dde8857a14d2f5340499ea40549f10cc3180c596e3f77efc8`。
- `decoded`：Apktool 3.0.3 完整解码及已应用的 API/密钥设置修改；没有依赖原 APK 的自动补丁步骤。
- `decompiled-readonly`：JADX 1.5.6 的全部阅读输出。99 处错误仅影响高级代码还原，不参与实际编译。
- `tools/apktool.jar`：Apktool 3.0.3，项目及许可见 https://github.com/iBotPeaches/Apktool 。
- `tools/android.jar`：Android SDK Platform 36.1，提供 Java 编译所需 Android API 声明。

- `tools/framework/1.apk`：本次解码/重建使用的 Android 资源 framework。构建显式使用包内 framework，避免依赖机器的全局 Apktool 缓存。
