# 项目简介建议

名称：`deepseek-native-api-rebuild`

简介：

> 面向特定 DeepSeek Android 2.7.1 版本的完整反编译重建工程，保留原生聊天界面，增加用户自填 API 密钥、官方接口校验与本机加密存储。

正文建议：

本项目研究如何从 Android APK 的编译产物重建可安装应用，并在保留原生交互的情况下将聊天链路适配到官方 DeepSeek API。工程包含原 APK 对应的完整 Smali、资源和 native 二进制，以及新增的 Java API 适配层、密钥设置实现和一键构建入口。

构建不需要再次提供原 APK，也不需要构建时注入 API Key。用户在“设置 → 账户 → API 密钥”配置自己的密钥，校验通过后加密保存，支持替换和清除。聊天记录保存在本机。当前覆盖文字聊天、基本思考展示和本地历史；语音、附件和搜索等原功能尚未接通。

工程不是官方原始 Kotlin/Gradle 源码。原 UI 等代码的编译输入是 Smali，JADX Java 输出只供阅读。包内 native `.so` 没有恢复 C/C++ 源码。

## 公开范围

这个全量工程包含原客户端反编译内容、资源、字体、native 库和工具，范围大于仅公开新增适配代码。维护者需确认自己有权公开的内容及各组件许可证，再决定仓库和 Release 的发布范围；本说明没有为原客户端重新授予许可证。

如只希望公开自己新增的代码，可单独发布 `src/local/api`、构建/修改说明，并另行处理原客户端来源。完整包适合本地重建，不应称为“官方开源完整源码”。

本次交付未创建或上传 GitHub 仓库。不要提交本机生成的 `build/development.jks`、API 密钥、聊天记录或历史个人专用 APK。
